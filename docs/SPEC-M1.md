# M1 module spec (interfaces are binding; two delegates implement A and B in parallel)

Runtime: Node >= 20, ESM (`"type":"module"`), **zero dependencies** (node builtins only), tests with `node:test`
(`npm test` = `node --test`). Style: small pure functions, every filesystem write behind a `dryRun` flag, errors
are thrown `Error`s with a clear message (no `process.exit` outside the CLI). English identifiers and comments.

Marker: every file/dir this tool creates is recognisable so it is never confused with user data:
- variant profile dir contains a file `.t3code-bridge-dsh` (JSON `{"source":"<name>","createdAt":"<iso>"}`);
- the variant's `cordis.patch.yml` starts with the line `# generated by t3code-bridge-dsh from profile <name>; run \`t3code-bridge-dsh sync\``;
- T3 provider instances owned by the tool: T3's schema may strip unknown config keys, so ownership is decided by
  shape, not by a marker key: instance ids matching `^dsh-[a-z0-9][a-z0-9-]*$` whose `driver` is `acpRegistry` and
  whose `config.commandArgs` is `["--profile", "<something>-acp"]`.

## Module A: dsh profiles and ACP variants (`src/profiles.js`, `src/variant.js`)

`src/profiles.js`
- `dshHome(env = process.env)` -> `env.DSH_HOME` or `~/.dsh` (absolute).
- `listProfiles({ home = dshHome() })` -> array of
  `{ name, dir, bundles: string[], appBundles: string[], isVariant: boolean, variantName: string, variantExists: boolean }`
  for every directory in `<home>/profiles` that has a `package.json` with `dsh.profile.bundles` (skip dirs without it,
  skip dot-dirs). `appBundles` = the bundles of that profile that are in `APP_BUNDLES`. `isVariant` = dir has the marker file.
  `variantName` = `<name>-acp`.
- `APP_BUNDLES` (exported, default array): `@deepseek-ai/dsh-web-app, @deepseek-ai/dsh-headless,
  @deepseek-ai/dsh-sdk-app, @deepseek-ai/dsh-sdk-minimal, ds-bot, @deepseek-harness-tui/dsh-tui, @open-design/dsh-runtime`.
- `ACP_BUNDLE = "@deepseek-ai/dsh-acp-app"`, `BASE_BUNDLE = "@deepseek-ai/dsh-base"`.

`src/variant.js`
- `planVariant(name, { home, appBundles = APP_BUNDLES })` -> a plan object, no writes:
  `{ source: name, target: "<name>-acp", sourceDir, targetDir, packageJson, patchYml, actions: string[] }`
  - throws if profile `name` does not exist, if `name` is itself a variant (`isVariant`) or already is the shipped `acp`.
  - `packageJson`: deep copy of the source package.json with `name` = `dsh-profile-<name>-acp`;
    `dsh.profile.bundles` = source bundles with every `appBundles` entry removed, and `ACP_BUNDLE` inserted right
    after `BASE_BUNDLE` (or first if base is absent); `dependencies` kept as is.
  - `patchYml`: the source `cordis.patch.yml` text with the marker header line prepended (or only the header + `[]` if the file is absent).
- `applyVariant(plan, { dryRun = false })` -> `{ created: boolean, updated: boolean, dir }`:
  creates `targetDir`; writes `package.json` (2-space JSON + newline), `cordis.patch.yml`, copies `cordis.yml`
  if present, writes the marker file; makes `<targetDir>/node_modules` a **symlink to `<sourceDir>/node_modules`**
  when the source has one (plugins stay resolvable without a second install). Idempotent: running again with no
  source change reports `updated: false`. Refuses to overwrite a target dir that exists without the marker file.
- `removeVariant(name, { home, dryRun = false })` -> `{ removed: boolean }`; only removes `<name>-acp` if it has the marker
  file; removes the node_modules symlink itself without following it; never touches the source profile.
- `syncVariant(name, opts)`: `planVariant` + `applyVariant`, returns the result (`updated` tells if it changed).

Tests (`test/variant.test.js`, all in a temp `DSH_HOME` built in the test): listProfiles finds profiles and ignores
junk; planVariant swaps the app bundle and keeps plugin bundles and order; patch header added; apply creates files and
symlink; apply twice is a no-op; refuses an unmarked existing dir; remove only removes marked dirs and leaves the source
and its node_modules untouched; dry run writes nothing.

## Module B: T3 settings and ACP probe (`src/t3settings.js`, `src/acpProbe.js`)

`src/t3settings.js`
- `t3SettingsPath(env = process.env)` -> `env.T3CODE_HOME` + `/userdata/settings.json` if set, else `~/.t3/userdata/settings.json`.
- `buildInstance({ profile, dshPath, displayName, accentColor })` -> the provider instance value:
  `{ driver: "acpRegistry", enabled: true, displayName, accentColor, config: { source: "local", commandPath: dshPath, commandArgs: ["--profile", "<profile>-acp"], enabled: true } }`.
  `instanceId(profile)` -> `"dsh-" + profile` lowercased, non `[a-z0-9]` runs replaced by `-`.
- `isOwnedInstance(id, value)` -> true only for the ownership rule at the top of this file.
- `planSettings(settingsObj, wanted)` where `wanted` is `[{ profile, dshPath, displayName?, accentColor? }]` ->
  `{ next, added: string[], changed: string[], unchanged: string[], removedStale: string[] }`; pure, never mutates its
  input; only touches `providerInstances` keys that are owned or new; non-owned existing keys with the same id are
  reported in `conflicts: string[]` and left alone.
- `removeOwned(settingsObj, ids?)` -> `{ next, removed: string[] }` (all owned instances when `ids` omitted).
- `writeSettings(path, next, { dryRun = false })`: backup `<path>.bak-<YYYYMMDD-HHMMSS>-bridge-dsh` (copy of the current file)
  before any change, atomic write (temp file in the same dir + `rename`), 2-space JSON + newline, file mode preserved;
  invalid current JSON -> throws without touching the file; dry run writes nothing and returns the diff summary.
- `readSettings(path)` -> parsed object (throws a clear error when the file is missing or not an object).

`src/acpProbe.js`
- `probeAcp({ command, args, env = process.env, cwd = process.cwd(), timeoutMs = 20000 })` -> Promise of
  `{ ok: boolean, agentInfo?, protocolVersion?, sessionCapabilities?, sessionCount?, error?, ms }`:
  spawns the command, sends newline-delimited JSON-RPC `initialize` (protocolVersion 1, clientInfo
  `{name:"t3code-bridge-dsh", version}`), then `session/list` (`params:{cwd}`), reads responses by id, kills the child,
  never leaves a process behind (also on timeout/error), never writes to the child's cwd. Resolve, do not reject.
  Reference of a working exchange: dsh answers initialize with `{"protocolVersion":1,"agentInfo":{"name":"deepseek-harness-acp"...},
  "agentCapabilities":{"sessionCapabilities":{"close":{},"list":{},"resume":{}}}}` and session/list with `{"sessions":[{"sessionId","cwd"}]}`.

Tests (`test/t3settings.test.js`, `test/acpProbe.test.js`): temp dirs only; planSettings add / unchanged / changed /
conflict; removeOwned leaves foreign keys; writeSettings makes a backup, is atomic, preserves unrelated keys byte-for-byte
in the parsed object, refuses invalid JSON; probeAcp against a tiny fake ACP agent script written by the test (answers
initialize and session/list), a fake that never answers (timeout, process killed), and a missing command (ok:false).
